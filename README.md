# Ondřej Dufek — personal website

A lightweight, mobile-first one-page portfolio for food product and category builder Ondřej Dufek.

## Positioning

Chef-trained. Product-minded. Built for scale.

The page follows the progression from ambitious European kitchens through Eska, Šodó and Živina to building Vilgain's fresh food and grab-and-go category.

## Technical approach

- semantic static HTML
- responsive CSS with no framework
- progressive JavaScript for swipe galleries and subtle reveal motion
- keyboard controls and reduced-motion support
- no analytics, cookies or external runtime dependencies
